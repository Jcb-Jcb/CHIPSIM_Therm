# 100 Chiplets Homogeneous

## What It Shows

This is the large homogeneous scaling example. It uses a 10x10 chiplet array
with the same layer stack style as the small homogeneous example, but with many
more chiplets and a much shorter timestep.

Run from this directory with:

```bash
bash run.sh
```

The script runs `thermal_RC.py` with `--is_homogeneous True`,
`--time_step 0.001`, `--power_interval 0.001`, `--total_duration 0.01`,
`--generate_DSS False`, and `--time_heatmap 0.0`.

## Inputs

- `system_geometry.yaml`: 100-chiplet homogeneous geometry.
- `power_dist.yaml`: one repeated `total` block per chiplet with
  `max_power: 2000`.
- `power_dist_chipsim_total.yaml`: alternate CHIPSIM-compatible total-power
  mapping file kept for the full-flow thermal adapter.
- `chiplet_power_1ms_avg.csv`: 1 ms power trace used by `run.sh`.
- `chiplet_total_power_over_time.csv`: longer CHIPSIM-style per-chiplet power
  trace available for inspection or conversion.

## Artifacts

- `floorplan/*.png`: node-numbered layer floorplans for the large 100-chiplet
  package.
- `floorplan/chiplet_power_.png`: power block layout for all chiplets.
- `output/power_all.csv`: 10 x 900 node-power matrix in watts.
- `output/temperature_all_0.001.csv`: 11 x 900 temperature matrix from 0 to
  0.01 seconds at 0.001 second resolution.
- `output/temperature_chiplet_0.001.csv`: 100 chiplet-average temperature
  traces.
- `heatmaps_first/`, `heatmaps_mid/`, and `heatmaps_last/`: archived heatmap
  snapshots from earlier analysis. They are not generated by the current
  `run.sh` name scheme. They appear to preserve heatmaps for early, middle, and
  final points in a trace so those states can be compared side by side.
- A fresh `run.sh` invocation writes one heatmap set to the default `heatmaps/`
  directory. The time used for that heatmap is controlled by `--time_heatmap`;
  this script currently sets `--time_heatmap 0.0`, so a fresh run plots the
  initial thermal state unless the script is changed.

## How It Differs

This is the scale test. It keeps the homogeneous assumptions from Example 1 but
uses 100 chiplets and 900 thermal nodes. It disables DSS generation because
900 x 900 state-space matrices are expensive and usually not useful for quick
example runs.
