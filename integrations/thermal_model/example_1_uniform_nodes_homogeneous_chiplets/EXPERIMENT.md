# Example 1: Uniform Homogeneous Chiplets

## What It Shows

This is the baseline thermal RC example. It models four identical chiplets in a
2x2 layout with uniformly spaced thermal nodes on every layer.

Run from this directory with:

```bash
bash run1.sh
```

The script does not use positional arguments. It changes to the parent
`thermal_model` directory and runs `thermal_RC.py` with `--is_homogeneous true`
and `--total_duration 50`.

## Inputs

- `chiplet_geometry_4_chiplets_uniform_nodes.yml`: 9-layer stack with uniform
  node counts. Only the `chiplet` layer is marked as a power source.
- `power_dist_config_homogeneous.yml`: four chiplets, each with one full-chiplet
  power block and `max_power: 3`.
- `power_seq_random_4.csv`: 50 one-second power samples for the four chiplets.

## Artifacts

- `floorplan/*.png`: node-numbered floorplans for each layer.
- `floorplan/chiplet_power_.png`: placement of the four chiplet power blocks.
- `heatmaps/*_heatmap.png`: per-layer heatmaps at the default heatmap time.
- `output/power_all.csv`: 50 x 192 node-power matrix in watts.
- `output/temperature_all_0.1.csv`: 501 x 192 temperature matrix from 0 to
  50 seconds at 0.1 second resolution.
- `output/temperature_chiplet_0.1.csv`: four chiplet-average temperature traces.
- `output/disc_A_matrix.csv` and `output/disc_B_matrix.csv`: 192 x 192
  discrete state-space matrices generated by the default DSS option.

## How It Differs

Use this as the reference case. Example 2 keeps the four-chiplet homogeneous
layout but uses non-uniform node placement and many smaller power blocks.
Example 3 changes to heterogeneous chiplet sizes and materials. The 100-chiplet
case scales this same homogeneous idea to a much larger system.
